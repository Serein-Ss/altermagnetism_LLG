## 🎯 当前唯一执行主线

当前用户接口和方法范围以[核心合同](GENERATIVE_DYNAMICS_SCOPE.md)优先；修订9[模型与物理决策](PATH_MODEL_AND_PHYSICS_PLAN.md)细化下一步。尺寸＋温度＋seed＋逐轴边界，模型包绑定体系与初态协议，方法可在1D/2D/3D分别训练生成。下述Bauer路线是首个实施案例。

同一Bauer体系 → 冻结物理问题与有限训练窗 → 共同小体系轨迹 → 单步A／整段B受控训练 → 同窗小体系验证 → 冻结模型 → 同窗尺寸推广、机制概率与成本。初态模块分离验证后集成；时间外推、文献长时寿命及其他体系随后分别推进。

这里的“完整路径”是已声明时间网格上的完整离散路径，不是已经证明任意尺寸、任意时间下的连续路径分布完全相等。

- 用户最新明确指令优先于历史文档；[项目总览](PROJECT_OVERVIEW.md)与工作计划管理当前阶段和结论，修订9细化方法对照，主协议及细则保留科学合同。

- [旧零场方案](ZERO_FIELD_GOMONAY_PATHS_AND_LITERATURE_COMPLETION_PLAN.md)仅为历史记录，不能据其旧矩阵重新启动任务。

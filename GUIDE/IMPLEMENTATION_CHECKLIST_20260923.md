## 🎯 目标、范围和当前基础

核心目标：同一Hamiltonian体系内，用小体系条件随机路径学习局域演化，通过多尺度时空模型在同边界的大体系中恢复主要动力学统计，并验证重复生成的计算价值。先完成Bauer一维开放链有限窗闭环，再分开验证尺寸和时间推广，最后扩展其他体系。有限支持域内的准确性是目标，不承诺全部极端稀有事件或无限时长无偏。

本清单汇总[核心主线](CORE_RESEARCH_MAINLINE.md)、[架构合同](MULTISCALE_STOCHASTIC_PATH_ARCHITECTURE.md)与[范围合同](GENERATIVE_DYNAMICS_SCOPE.md)。相冲突的旧阶段执行顺序以本清单及最新用户确认合同为准，历史实验和结果不追溯改写。优先级表示依赖与资源投入顺序，不表示只有零误差才允许后续探索。

根据[已有测试记录](../tests/spin_graph_20260920/README.md)，可复用基础是局域SpinGraphNet、时间注意力、FiLM、球面采样接口及11项新旧软件回归；Bauer L16的50步训练和4条1 ps路径只是冒烟。完整多尺度、目标晶格有向键几何、权威能量统一及本轮独立统计认证仍待完成。本次未检查队列、重跑测试或审计全部历史数据，不能把此处状态当作实时任务状态。

当前不做：学习式初态生成器、单模型混合边界或跨边界迁移、完整体系／温度／尺寸全矩阵、默认CG／CFG强化、强制全部极端事件认证。单温度先导不代表温度依赖已学会；同一方法覆盖多维不等于一个checkpoint跨维度通用。

## ⚙️ P1：冻结首轮合同并补齐实现

### P1-A 数据、指标与预算合同

- [ ] 选择能显示可测量演化且已有数据支持的有限时间窗；不为了容易通过而压短窗口，也不默认首轮直接做完整10 ns。
- [ ] 固定训练尺寸、单温度、开放边界、初态协议及输出网格；登记支持域与物理转换。
- [ ] 父状态及相关准备来源分组后再截窗；分别保存训练、开发和最终测试manifest。必要的新划分须版本化，不改冻结旧划分。
- [ ] 分别根据状态覆盖和指标精度安排父状态／分支数，不凭空规定大矩阵。
- [ ] 冻结主要指标、预先确认的物理容差、固定父状态或来源总体的估计目标、重采样单位和选模规则。
- [ ] 冻结模型宽深、优化设置、参考潜变量、窗口、flow步数候选、至少三个训练seed及预算口径；先估时，再决定任务提交。

交付：可复现的实验配置、数据清单、指标说明及预算表。窗口、数据量、辅助权重、阈值和运行时间均是待预检值，本清单不虚构数值。

### P1-B 局域模型、采样和评估

- [ ] 复用局域标量—向量图候选，核对联合SO(3)变换、切向输出、实际初态固定和绑定边界；不要求镜像等变。
- [ ] 训练集条件标准化写入模型包，常量条件显式处理；seed只控制抽样，不作为物理输入。
- [ ] 审计球面近重合／近对跖数值处理、flow训练目标与完整采样协变性；运输时间与物理时间分离。
- [ ] 检查块内真实未来条件泄漏、物理帧时间、模型包元数据及checkpoint恢复。
- [ ] 接续接口检查末态传递、必要历史、独立随机流、帧去重、末块前缀、非网格终点处理及断点恢复；不改变旧checkpoint时间含义。
- [ ] 评估器输出能量、磁化、条件增量均值／协方差、时间关联和空间相关；测试已知／合成情况及维度单位。
- [ ] 置信区间保留独立分支／来源结构，不把帧和格点当独立样本；真实分位带、均值置信带和差值置信带分别标注。

交付：有日志的回归测试及一次真实数据训练—采样冒烟。软件通过不表示随机动力学已正确。

## 📊 P2—P3：首轮闭环与核心对照

### P2 局域基线闭环

- [ ] 使用冻结配置开展至少三seed的局域条件流训练；保留仅流匹配基线，开发集选模，最终测试不参与调参。
- [ ] 同父状态生成独立未来，检查flow步数收敛；增加步数不代表增加物理时长。
- [ ] 主网页展示真实／生成完整时空图、能量分布与时序、增量统计、时空相关、差值与不确定性及成本。
- [ ] 分别报告支持、偏差和证据不足；不使用任意综合分数掩盖分项失败，不把相对最好称为通过。

交付：checkpoint与配置、生成路径、分项JSON／表格、PNG、网页入口及结论。1D以完整时空图为主，不强制动画；二维后续可提供GIF。网页结果标注模型／数据版本及“软件检查／开发评估／最终测试”身份。

### P3 三组贡献对照

- [ ] 局域／多尺度：实现细粗图双向交互及跳连，保留粗向量模长；测试聚合计数、奇数尺寸、边缘、周期和对齐偏差，登记尺度覆盖与参数共享。
- [ ] 单步／联合块：最终物理任务和输出网格可比，检查时间关联、累计偏差及实际成本，不预设联合生成必胜。
- [ ] 仅流匹配／能量辅助：使用P0-B通过的可微能量，比较同初态集合统计；明确训练用Hamiltonian知识，禁止能量守恒或任意随机路径逐帧能量配对损失。
- [ ] 能量辅助只作用于合理的物理路径估计，不强迫flow中间草稿符合真实能量分布；登记采样反传和成本。
- [ ] 各对照保持主要非目标因素一致，报告参数量、实际算力和至少三seed稳定性；有依据再补交互实验，不自动全组合。
- [ ] 所有改动检查未直接优化指标及多样性，保留负结果；历史确定性／简单随机基线有适用合同则保留，不能冒充完整路径模型。

交付：逐项增量证据和候选选择理由；未通过先诊断。无需等全部对照都胜出才报告可用局域基线，但多尺度贡献必须有自己的证据。

## 🔧 不通过时的诊断与执行纪律

诊断按低成本、能归因的检查优先：物理／数据／指标一致性；固定checkpoint与潜变量的flow收敛；小批次拟合；训练内与独立父状态差异；单块与接续差异；同窗尺寸差异。它们提供线索而非唯一病因证明。每次改动写清假设、固定变量、观察指标和支持／否定依据，不盲目加预算。

该诊断顺序是对已有“失败先定位”的操作展开，并非已执行的诊断或新增自动任务。发现物理来源矛盾先处理，不能通过降低阈值让结果通过。

- 全部项目计算使用zrs-mag；新增实验代码、配置、日志、数据和结果在tests下，验证及用户批准后才晋升正式目录。
- GPU通过Slurm、rtx4090分区、zrs-mag任务名和CUDA设备；大批CPU数据生成使用fat，不占登录节点做无界长任务。
- 提交前估时；超过10分钟提交并确认受理后不持续监督，待用户通知再检查。短任务可监督。只提交已满足前置条件的任务，不自动铺满所有后续阶段。
- 不因本清单删除历史数据、修改冻结配置、终止旧任务或推送仓库；GUIDE可推送，data仍排除，本次没有Git操作。
- CFG是可选受控对照，CG需另行论证；学习式初态、跨边界泛化和极端尾部认证不成为首轮前置条件。

每项完成时记录：任务ID、代码／配置版本、数据来源与split、测试日志、结果路径、适用域、结论及下一步。只有交付物和验收证据存在才勾选，不用队列退出码代替科学验收。

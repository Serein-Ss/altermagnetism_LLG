## 一、目标、范围与文档优先级

主线为**Bauer小体系短轨迹学习 → 未见大体系长轨迹生成 → 文献统计独立对标 → 经文献对照与热扩展认证的交错磁体系**。训练数据提供相互作用诱导的随机时空样本；最终寿命、返回、空间关联和机制性质从冻结模型生成的路径中统计，不以复制训练集经验分布为最终目标。其他文献任务独立保留，不额外增加宏自旋或普通AFM作为主线必经体系。

**研究假设**：在同一Hamiltonian参数、热浴、阻尼和边界类型下，有限小体系短轨迹包含足够的局部状态与随机演化信息；具有适当空间组合与时间延展能力的模型可以预测未用于训练的大体系、长时间可观测量。该假设须由外推实验验证，不能由模型输出尺寸可变、球面约束或大量采样自动推出。

**训练前不要求完整重跑文献的大体系长模拟。** 小体系数据首先通过方程、单位、基础物理、数值分辨率与状态覆盖检查；大体系文献结果作为冻结模型的外部检验。少量针对性的独立模拟用于必要的过程或误差检查，不默认生产与生成样本等量的大体系完整路径库。已发现的共用内核错误仍阻断依赖它的数据；未完成的整篇文献扫描不等于小体系数据已经错误。

目标是有限物理时间网格上的条件联合分布：

```math
p_\phi(Y_1,\ldots,Y_{F-1}\mid S_{init},h,\vartheta,\mathcal C,G,\{\tilde t_f\}),
\qquad Y_0=S_{init}.
```

其中方程合同包含 `equation_convention,damping_parameter,damping_value`；Bauer使用lambda，Gilbert使用alpha。随机性来自固定初态之后的热噪声，不通过更换初态制造，也不等同于确定性混沌。参考模拟、生成分布与计算收益分别验证。

“完整路径”指全部保存帧的离散路径；连续时间快过程、长时和稀有事件结论仅在对应分辨率/统计验证范围内成立。经典主线必做空间与时间联合外推：`L_test > max(L_train)`且`T_test > max(T_train_window)`，同时区分空间单独、时间单独和联合外推。温度泛化为可选新增维度，不能替代这两项。留出值及文献目标最迟在P2结束锁定，不参与P3调参，P4冻结确认性合同，P5完成；已用于分析和修改的条件不能重新宣称盲测。新噪声seed不构成物理条件泛化。

“学习机制”在本协议中指经外部可观测量检验的可迁移动力学规律，不宣称唯一识别相互作用或因果机制。Hamiltonian还需配合随机方程、阻尼、温度、边界及准备协议才能确定路径律。已知参数在本项目中是条件或物理先验，不是默认的逆问题学习目标。更多生成样本只减少给定模型下的Monte Carlo误差，不能消除训练数据不确定性、模型偏差或尺寸/时间外推误差。

球面约束、SO(3)协变性和可审计数据是方法质量保障，不单独构成创新。潜在贡献是“有限小体系短轨迹训练，在无目标大体系训练数据的条件下预测长时随机事件及机制统计”，不是仅让网络支持更大张量或预测已知局部场。须与局部力场/力矩学习、学习转移模型及直接路径生成分别比较；在简单近邻Hamiltonian上，主要计算收益应来自时间采样而非省去廉价场计算。分布准确性、相对学习方法的表现和计算收益分开报告；未完成逐篇近邻比较不使用“首次、通用、无偏”。

## 二、当前Bauer案例与物理合同

### 2.1 单位、Hamiltonian与特殊随机LL

配置保留 `source_parameters / reduction / reduced / numerics` 四层；原值、单位、图号/版本与换算可复算，数值选择单列。定义 `h=H/E0,theta=k_B*T_bath/E0,b_i=-∂h/∂S_i`，单位自旋且无向键仅计数一次：

```math
\begin{aligned}
h&=-\sum_{(i,j)\in E}j_{ij}\mathbf S_i\cdot\mathbf S_j
-\sum_i\kappa_i(\mathbf S_i\cdot\mathbf e_i)^2-\sum_i\boldsymbol\beta_i\cdot\mathbf S_i,\\
\mathbf b_i&=\sum_jj_{ij}\mathbf S_j+2\kappa_i(\mathbf S_i\cdot\mathbf e_i)\mathbf e_i+\boldsymbol\beta_i.
\end{aligned}
```

正键权为FM、负键权为AFM；文献正幅值与有符号邻接权重分开。登记基点、位移、端点、计数、边界及符号，核对配位、基态和负梯度。当前单轴Bauer开放链可取`E0=J`、近邻`j=+1`、`kappa=K/J`；具体案例按原文冻结，不沿用Gomonay参数。

[Bauer原文Eq.(2)与附录A](https://arxiv.org/html/1010.4730v2)采用`hbar*∂S/∂t=...`。因此按该原文约定，`t0=hbar/E0,tilde_t=t/t0`，约化Stratonovich方程为：

```math
\begin{aligned}
d\mathbf S_i={}&-\mathbf S_i\times\mathbf b_i\,d\tilde t
-\lambda\mathbf S_i\times(\mathbf S_i\times\mathbf b_i)\,d\tilde t
-\sqrt{2\lambda\vartheta}\,\mathbf S_i\times\circ d\mathbf W_i,\\
E[dW_{i\mu}dW_{j\nu}]={}&\delta_{ij}\delta_{\mu\nu}d\tilde t.
\end{aligned}
```

必须登记 `equation_convention=bauer_ll`；噪声只进入进动项，无Gilbert式的`1/(1+alpha^2)`整体因子，不把lambda静默改名或数值等同于Gilbert alpha。原文寿命与本项目固定初态首达统计分别定义。

对其他相同磁矩/旋磁比的通用模型，`t0=mu_ref/(gamma*E0)`，gamma为以B场定义的正旋磁比，`mu_ref`是磁矩而非真空磁导率。若用这组参数表示Bauer时间单位，须证明`mu_ref/gamma=hbar`或显式记录重新标定；不能假定所有材料满足。SI Zeeman项为`-mu_ref*B_ext dot S`，`beta=mu_ref*B_ext/E0`；不同位点磁矩/旋磁比需另行推导。Gilbert完整随机式及AM参数见[模型附录](RESEARCH_PROTOCOL_AM_APPENDIX.md)。

零场路径强制外场、场梯度、SOT、STT、电流和脉冲为零，保留内部交换与各向异性场。有场/有流文献复现独立归档。

### 2.2 案例、机制与温度窗口

P0登记选定原文版本、图号、L、K/J、lambda、温度、边界、初态协议、时间单位和目标；具体原条件及容差沿用[严格计划第7节](STRICT_LITERATURE_REPRODUCTION_PLAN.md#7-bauer-et-al-2011)。同参数的小尺寸、短窗口训练明确标为`training_extension`，允许在小体系数据认证后先行，不以完成全部大体系寿命扫描为前置。原条件及其公开统计保留为外部目标，未通过不能宣称文献复现完成；未公开dt、随机流和准备细节属于复现选择，不能宣称重放作者逐条路径。

首选外部锚点为Bauer Fig.2的`L=100,K/J=0.1,lambda=0.1,theta=0.11`及与主张对应的Fig.1/3寿命、能垒或长度规律。Fig.2示例只能提供定性过程证据，不能从单条示例推断未公开的路径概率。每个定量目标登记原文图号、数据点、数字化误差、统计定义和可比条件；原文未给出的量不虚构真值。跨温度拟合只在实际预注册温度范围内声称，不将改变温度的结果隐去。

无需作者相同的初态数组或噪声seed：稳态统计须匹配准备协议并验证热化、平稳及混合；初态条件首达须匹配初态类别/分布或给出敏感性证据。多条短路径不能自动替代长时寿命，许多副本也不能绕过模型的时间延展验证。

| 物理前提 | 需登记的证据和判定 |
|---|---|
| 双稳态适用性 | Bauer反转研究要求L相对相关长度xi(T)足够小。P2用独立参考数据，登记相关长度估计器、适用假设/不确定性、相关函数与磁盆证据；不能只凭磁化越零宣称双稳态 |
| 目标机制 | 以晶格间距为长度单位，连续近似`L_DW≈2*sqrt(J/K)`仅供选区。`L<<L_DW`偏整体转动，`L>>L_DW`支持成核/传播；交叉区需实测，不能把近似当精确分界 |
| 成核/畴壁指标 | 主研究若针对边缘成核与传播，须有对应长度区间和空间轨迹证据；整体转动案例中畴壁指标标`not_applicable`并给理由，不能把未发生畴壁判为求解器失败 |
| 可负担事件 | 先导联合检查事件数、删失率、驻留与成核过程的分辨率；升温或缩尺寸后重查磁盆、相关长度和机制，不能以无序涨落代替目标反转 |
| 不满足条件 | 目标状态/过程未覆盖或不可解析时记HOLD/定向补充。短训练窗未出现完整大体系翻转本身不判失败，但须覆盖主张所需的局部过程并在P5外部检验；不能仅用生成器自身证明缺失机制 |

Bauer原文寿命是长轨迹中相邻反转间隔的平均；本项目从固定初态出发的首达/生存不是同一估计目标，两者分别计算。候选初态不强制三类全覆盖，有限链不使用未经定义的T/T_N；AM温标见附录。

### 2.3 积分器及数值认证

**保留确定性RK4；Bauer原条件使用其特殊LL和弱随机RK。** 有限温通用Gilbert路径另选认证过的随机方法，不统一替换现有求解器。

| 方法 | 角色和必须检查 |
|---|---|
| 普通RK4 | 无热噪声的确定性LLG；时间步、投影前误差、相应守恒/耗散 |
| Bauer弱随机RK | 登记具体算法/文献及离散随机变量；按目标弱统计和步长认证，不宣称普通随机四阶 |
| 随机Heun | Stratonovich候选；同一步预测/校正复用同一Wiener增量，投影方式明确 |
| 几何隐式midpoint | 代表条件的几何/数值交叉验证；记录残差、迭代容差和失败，模长保持不等于分布正确 |
| 其他文献方法 | Nishino显式midpoint独立登记；不能与几何隐式midpoint混称。LLB纵向自由度不适用单位球面证书 |

Wiener增量按sqrt(dt)缩放。强收敛比较使用合法嵌套增量，粗增量等于细增量之和，必要时用Brownian bridge；弱统计可独立抽样或采用合法耦合。弱RK离散随机变量不能冒充共同Wiener强路径。普通RK4的确定性阶数不能外推到白噪声方程。[方法来源](https://arxiv.org/abs/1002.1801)

记录预测/最终投影前误差、投影选择和数值失败。小尺寸交叉验证不替代实际用于定量对标的大尺寸参考模拟自身的步长及观测量收敛；不据此要求训练前完成全套大尺寸长模拟；主方法按误差、稳定性、单位有效样本成本冻结，不预设Heun/midpoint必然优于RK类。物理dt、保存间隔和RFM运输积分步数分别认证。

## 三、完整离散路径RFM

### 3.1 随机源、锚定与几何

Y形状为`[B,F,A,Nx,Ny,3]`，B为batch、F为物理帧数、A为基点数。开放链为`A=1,Nx=L,Ny=1`，邻接不得连接首尾。自由流形为`(S²)^((F-1)*A*Nx*Ny)`。每次独立采样参考路径Z并硬设`Z[:,0]=S_init=Y[:,0]`；其余帧的源分布、时间相关、尺度和seed冻结。潜变量噪声不等于真实LLG热噪声，不要求两者逐点配对。

```math
\begin{aligned}
\Pi_s(v)&=v-(s\cdot v)s,\\
\operatorname{Exp}_s(v)&=\cos\|v\|s+\frac{\sin\|v\|}{\|v\|}v,\\
U&=\operatorname{Log}_Z(Y),\qquad X_\tau=\operatorname{Exp}_Z(\tau U),\qquad V_\tau=\partial_\tau X_\tau.
\end{aligned}
```

Exp输入须在切平面，tau是运输时间，不是物理时间。第一帧恒定、速度为零并排除损失；不能用以S_init为唯一源的插值替代随机Z。小角度稳定极限及反足/cut-locus处理须测试并报发生率，不能隐蔽丢弃困难真路径。源尺度消融不改变真实热浴。[RFM来源](https://arxiv.org/abs/2302.03660)

### 3.2 网络、条件与适用对称性

输入`X_tau,tau,S_init,c`，c必须实际携带或通过模型绑定明确提供：theta、方程约定和阻尼定义/数值、全套约化键/各向异性、物理帧时刻、窗口、保存间隔、基点与边界。按模型提供晶轴、键向量及相关张量；不能只写进配置而未被模型消费。

标量不变量网络与逐块FiLM产生系数，组合自旋、邻域差分、Hamiltonian场及必要叉乘协变基，切向投影后输出同形速度；应能表达进动结构。归一化逐位置作用于通道，避免隐含尺寸统计。PeriodicConv3d只代表规则周期实现；开放链/多基点/图接口须真实验证，裁剪需足够halo或全局邻接。

| 变换 | 适用范围及核查 |
|---|---|
| 联合proper SO(3) | 同时旋转自旋、初态、场、易轴及张量；检验坐标协变，不把固定易轴模型说成任意自旋旋转对称 |
| 平移 | 只对具有相应周期边界/参数的方向；开放链不要求循环平移 |
| C4与子晶格/位移 | AM按实际晶胞、Hamiltonian和边界登记联合映射；不默认要求开放链、长方形或开放样品具备固定几何C4不变性 |
| 重编号/图置换 | 同步变换邻接、基点、参数和条件，比较同一物理系统的表示 |
| 反射 | 自旋/DMI等变换另行推导，当前不声称E(3) |

冻结`symmetry_registry`列适用操作、映射、容差与不适用理由。网络、源采样器和最终生成分布分别验证；通过SO(3)不证明材料泛化。

### 3.3 训练与推理

采用乘积球面的平方范数，以下求和包含全部自由帧和自旋位点：

```math
L_{FM}=E\left[\frac{1}{(F-1)AN_xN_y}
\sum_{f=1}^{F-1}\sum_{a,x,y}\|v_{\phi,faxy}(X_\tau,\tau\mid S_{init},c)-V_{\tau,faxy}\|^2\right].
```

硬锚定和切向投影优先于重复软惩罚。Hamiltonian辅助项若启用，冻结数学定义、适用系综、权重和消融；有限温不施加能量守恒损失，不对未解析热增量施加确定性LLG残差。推理从新Z出发，用几何积分从tau=0到1并固定初帧；训练、潜变量、真实噪声三类seed分别登记，编号相同不代表耦合。

### 3.4 跨尺寸与长时间生成：当前核心开发任务

以下是设计与验收要求，不代表当前GateFNet已经具备这些能力。只改变输入张量L/F或把时间重新归一化到[0,1]不构成外推。

| 能力 | 设计合同与检查 |
|---|---|
| 空间组合 | 共享局部规则、实际Hamiltonian邻接/易轴/边界条件；区别真实链端与内部。子域裁剪保留halo或边界环境，不能把小开放链反复拼成带伪边缘的大链 |
| 相关结构 | 增大尺寸后检查长程关联与集体事件；有限感受野、独立局部源和邻域消息传递次数的限制需量化，不假定局部拟合已确定全局联合律 |
| 条件轨迹块候选 | 给定当前完整自旋状态，联合生成下一物理时间块，再用末态续接；全状态白噪声Markov条件下使用独立新潜变量，有记忆热浴须增加状态。该方案是候选，不替换为逐自旋独立采样 |
| 整段生成候选 | 一次生成未见大尺寸/长窗口，须显式表示物理时间、检查窗口边缘化及共同子窗口的一致性；固定训练窗模型不能仅拉长时间标签 |
| 时间一致性 | 比较一次2Δ块与连续两次Δ块的转移/路径可观测量，并在允许的小体系独立参考上交叉验证；模型自洽本身不证明物理正确。检查块边界、累计漂移、生存及相关性 |
| 分辨率 | 物理dt、保存间隔、块长、总长和运输步数分别登记。只保存粗帧可学习对应粗时间转移，不能据此声称恢复高频谱或连续成核细节 |

P3用开发数据比较必要的候选/消融后选定一路，P4前冻结；本次修订不强制更换RFM、训练模型或启动计算。条件块有利于明确时间组合，但仍可能累积偏差；整段生成仍允许作为目标方案，不能预先保证其规模或速度收益。RFM运输速度不是LLG物理速度，有效场预测准确也不等于路径概率准确。

## 五、验收合同：开发、确认与成本

### 5.1 共同指标和统计原则

| 指标 | 正确的比较与边界 |
|---|---|
| 能量 | 零温无阻尼无驱动查守恒，有阻尼查耗散；有限温非平衡查热化曲线/分布，平衡查集合平稳，单路径允许涨落。用每自旋约化值/固定尺度，初能量近零不除以它 |
| 逐点路径距离 | 仅用于确定性极限、明确耦合或描述；独立真/生成路径任意配对不作主排名 |
| 分布 | 固定初态比较MMD/energy distance(ED)，冻结特征、核/距离、时间权重、归一化；等样本LLG–LLG是抽样参照，不是所有生成误差的自动校正 |
| 空间和谱 | 结构因子使用实际基点/子晶格/归一化，跨尺寸用共同物理波矢；谱登记采样率、时窗/窗函数、分辨率、激发支持和单位 |
| 相关与事件 | ACF/ESS只用于适合的平稳段，检查慢尾、窗口敏感性、多链/多观测量；固定初态非平稳反转另查时序联合统计、首达和机制，不机械用稳态ACF |
| 对称与数值 | 按3.2适用表验证；模长和SO(3)通过不代表路径统计正确；物理dt、保存频率、运输步数分别收敛 |

固定初态以独立噪声路径为重复；跨初态采用初态—噪声分层bootstrap；有相关来源时按来源链/时间块再聚类，窗口与重复事件按父轨迹处理。训练seed波动单报。bootstrap至少2000次并记seed，具体区间算法、聚类层次、共享样本依赖、多重比较族和覆盖率校准须在合同中确定；次数本身不保证覆盖率。少数初态的区间可能不稳，增加噪声数不能代替增加初态数。

CI重叠或不显著不等于等价。宽CI记inconclusive；事件样本量依据先导效应/概率与CI精度目标确定。独立n条完整窗口路径零事件时，单侧95%概率上界为`1-0.05^(1/n)`：n=32约8.94%，n=128约2.31%；这不是物理反转概率的点估计。

### 5.2 Gate-F：P3开发可行性

本节的44维指标和固定窗口门槛作为小体系开发筛查，不能当作大体系文献真实性标准。修订5下新块长/特征的模型须注册相应新合同和数值容差，不能机械沿用旧归一化与阈值；现有第一轮结果保持探索性历史状态。

P3每个实验版本开始前冻结`gate_f_contract.yaml`：版本/来源、案例、初态与数据清单、theta/阻尼、时间网格、模型/基线、seed、特征/尺度、磁盆/事件、误差容差、样本数/功效、检验族、查看次数、补样规则和预算。缺项不训练。以下是项目技术阈值，不是文献常数、10%物理误差或投稿充分条件。

令`D=ED(G,R1)-ED(R1,R2)`。ED固定为经验V统计量（含组内对角项）；先在每个固定初态计算，再按初态等权汇总并按冻结条件组报告。主特征为每自旋约化能量和M三分量在11个固定时点的44维向量；训练尺度标准化后，基础欧氏距离除sqrt(44)。方差过小的尺度下限按物理尺度预定，不用测试统计选择。它只覆盖这些特征，不能验证所有离散路径信息。

为避免ED是否开平方、是否使用U统计量的实现歧义，本合同定义（不再开平方）：

```math
\widehat{ED}_V(X,Y)=\frac{2}{n^2}\sum_{i,j=1}^{n}d(x_i,y_j)
-\frac{1}{n^2}\sum_{i,j=1}^{n}d(x_i,x_j)
-\frac{1}{n^2}\sum_{i,j=1}^{n}d(y_i,y_j).
```

其中d为上述标准化后除sqrt(44)的距离；如果另定义特征/距离，必须注册新指标及相应容差，不能直接继承0.10。

表中“同时CI”置信水平统一由本节的查看方案决定，不同时混用95%与97.5%。

| 必须项 | 技术GO条件 |
|---|---|
| 完整性 | 数值有限，哈希/来源/划分通过，无未声明丢样或未解决数值失败 |
| 模长与初态 | float32最大绝对误差各<=1e-5，float64各<=1e-10 |
| 网络协变 | 至少20个冻结联合SO(3)变换；float32相对误差<=1e-4，float64<=1e-8；分母`max(norm(output),1e-8*sqrt(numel))`，另报绝对误差。其他适用变换也列入合同；源与生成分布另测 |
| 主分布 | 每个冻结条件组D的同时CI上界<=0.10 |
| 条件均值 | 主特征生成—独立参考均值差的同时CI完整位于[-0.10,0.10] |
| 物理系综 | 通过所选非平衡热化或稳态窗口检查；无全局平衡证据不报全局稳态GO |
| 学习基线 | 同数据、可比训练/调参预算比较确定性/平均场、欧氏flow、简单随机自回归。相对所有注册学习基线的ED差同时CI上界<=0.02，才能称对该集合最佳基线非劣；优势须相应上界<0，不能测试后挑基线 |
| seed与采样步数 | 三训练seed分别通过，不能平均后才通过；共同潜变量作步数加倍检查，主特征均值差同时CI位于[-0.05,0.05]；事件敏感性及完整路径诊断一并记录 |
| 事件与机制 | 反转概率、生存/RMST、返回及适用成核/传播指标按P2冻结容差和功效通过；整体转动案例使用其机制指标。证据不足记HOLD，不能以仅涨落GO替代反转主线 |

事件和机制容差不填任意默认常数；P2先导结束须填写数值、物理单位/概率尺度、共同时间范围及精度依据。空间关联、时序联合量、适用ACF/谱、尾部和失败样例均保存；11时点ED不能替代这些证据。

| 预注册查看方案 | 区间与补样规则 |
|---|---|
| 单次 | 仅一次查看，使用95%同时CI，不追加到显著 |
| 最多两次（保留原开发默认） | 初始n0，最多一次补充、总上限2n0，生成与真实同步匹配；每次使用97.5%同时CI，总错误预算按两次各0.025分配 |

检验族事前列全条件、特征、seed、基线与事件。共享R1/R2或共享潜变量在重采样中联合处理。两次查看的总预算解释以每次区间具有适当覆盖率为前提，bootstrap仅给近似保证，须记录方法适用性和校准结果。P3可迭代模型，但每次变更留新contract_id与完整开发历史；错误预算只解释单个冻结版本，不能把跨版本择优当最终盲测。

GO仅为开发技术可行；HOLD为证据/精度不足，补充后仍不足则该版本inconclusive；STOP用于内核错误、泄漏、非有限值或预算超限。修复后需重新认证相关依赖，旧数据不静默改为测试。

### 5.3 P4/P5：独立确认性合同

P4冻结`confirmatory_contract`及模型、权重、采样器和数据哈希，P5仅用生成模型在未训练的大尺寸、长时间条件下生产预测路径，再计算性质。大体系完整参考轨迹不作为训练必需品；文献数值、解析关系及预注册的少量独立模拟提供外部检验。默认95%同时CI，明确公开文献已知、但未用于参数/模型选择的检验性质，不冒称文献结果对研究者不可见。

| 必须预注册的项目 | 填写内容与通过条件 |
|---|---|
| 训练与外推范围 | 列所有训练L、窗口、温度、初态支持；列空间单独、时间单独及联合外推。联合任务必须L和时间窗均严格超出训练支持，不能用新seed或温度留出替代 |
| 初态/稳态协议 | 不匹配作者噪声实现或某条示例；匹配初态分布、热化、观察窗、事件定义。稳态寿命检验平稳与混合，固定初态首达另报 |
| 文献主结果 | 至少一个有定量数据的预定目标，例如多个留出长度的寿命规律，或多个温度的寿命/能垒；列图号/点值、误差、拟合范围和物理容差，示例轨迹不能充当概率真值 |
| 独立路径/机制结果 | 至少一个与主平均量不同的检查，例如返回、空间关联、成核位置或传播；有文献数值则定量对照，只有定性描述则仅报定性支持，必要时小预算独立模拟补足 |
| 小体系内部有效性 | 保留独立条件路径/转移与短窗组合检查。训练集距离仅诊断拟合和记忆，不是最终科学目标；无需大体系G与参考等样本，仅在直接ED比较时控制样本量效应 |
| 数值一致性 | 所选生成机制检查运输步数、块长/时间范围、保存分辨率、段界及窗口一致性；使用的独立模拟自身须有对应数值误差证据，不从小系统证书外推大系统参考精度 |
| 不确定性与预算 | 分开报告生成采样误差、训练seed/数据子集变动、文献读图误差及参考数值误差；N_gen、查看次数、停止/补样规则提前确定。大量生成不能使模型偏差消失 |
| 基线和成本 | 相同小体系训练支持与可比调参预算；基线需要实际支持外推。额外使用大体系训练的模型另列；纯生成与LLG校正混合分开核算和命名 |

所有容差、单位、主次指标及适用范围在P4前填成数值；未公开的文献误差不虚构。数据精度不足记inconclusive，不以CI重叠证明等价。原文相邻翻转寿命、首达/RMST及有限窗事件率分别定义，有限窗口截断必须分析。

P5同时满足预注册外推主结果、独立路径/机制检查及数值要求，才能支持“在这些条件与观测量上具有跨尺寸、跨时间预测可行性”。只匹配单个均值仅支持该量的初步可行；有限指标不证明全路径律完全一致或唯一识别机制。额外完成成本目标后才声称科学加速。

看过外部结果后若修改模型/采样器/阈值，该结果转为开发证据；另留未参与修改的文献条件、独立预测量或新独立参考作确认。不能反复对同一文献曲线调参后称零样本预测。所有失败条件、训练seed和模型版本保留。

### 5.4 成本与结论分工

在相同目标误差、观测量、有效样本量、硬件与优化batch下比较；记录精度、函数评估次数、I/O、显存、CPU/GPU小时与有效吞吐。依赖ESS时说明观测量及估计器，不把高相关窗口数当独立样本数。未闭合精度只报吞吐；下采样损失与算法收益分开。

设每个匹配有效样本的参考成本为c_ref、生成成本为c_gen，固定成本C_fixed包含实际用于方案的数据生产、训练、调参和验证；另报一次性研究开销与部署可复用成本边界。近似线性成本范围内：

```math
S_{infer}=c_{ref}/c_{gen},\qquad
C_{gen,total}(N)=C_{fixed}+N c_{gen},\qquad
N_{break}=C_{fixed}/(c_{ref}-c_{gen}).
```

仅当`c_ref>c_gen`时存在该正盈亏点；否则报当前范围未获得摊销收益。batch/硬件随规模改变时使用实测成本曲线，不能外推固定单价。

| 判定 | 对研究推进和主张的影响 |
|---|---|
| 分布/事件准确性及必做泛化通过 | 加上小体系数据数值认证与5.3外部物理验证，可进入P6；结果只覆盖注册条件、分辨率与观测量 |
| 学习基线非劣/优势 | 独立记录，Gate-F仍须满足5.2的非劣门槛；P5若未确认优势，不声称方法优越，必要时回开发新版本 |
| 计算收益 | P4预先登记计划使用量N_target、成本核算边界及收益不确定性；只有精度通过且目标N下总成本收益成立，才声称该使用场景的科学加速 |

准确但未获成本收益允许继续物理/方法研究，需明确局限，不把推理吞吐或硬件差异包装为总加速。长时和混合算法重新核算。

## 七、进入交错磁与后续扩展

## 🎯 2026-09-20用户确认：固定边界类型的尺寸迁移

当前只要求同一模型在训练和目标大体系中保持相同边界类型：开放训练用于开放大体系，周期训练用于相同周期设置的大体系。不要求一个checkpoint支持多种边界，不要求开放／周期之间迁移。

- 边界绑定模型包、数据manifest和checkpoint元数据；逐轴周期标记、开放／固定边缘的处理、长程相互作用边界约定均须一致。若采用混合逐轴边界，其组合也保持不变。
- 改变尺寸不改变晶格维度、物理体系或边界协议；开放边缘随尺寸增加仍存在，不能将边缘动力学忽略为周期体内动力学。
- 生成时从模型包加载边界配置，不再把边界切换作为必需的用户自由度。兼容接口若保留`pbc`，后续实现必须校验与模型登记值一致，不匹配时拒绝或要求加载对应模型，不得静默切换。
- 不为单个模型混合多种边界数据；按所选文献或研究体系的目标边界分别训练、评估和存档。不要求每个体系都额外制作开放及周期两套数据。
- 几何软件可复用开放和周期算子，但代码支持多种边界不等于同一checkpoint在多种边界下学会动力学。保留适用边界的正确性测试，不把跨边界泛化作为验收门槛。
- 任何未来跨边界研究需用户另行确认；本次仅修改范围与开发约束，不删除既有代码／数据，不改冻结配置、不取消或重提任务。本节的接口校验是后续实现要求，不宣称已修改现有采样代码。

## 🎯 核心研究目标

开发一套样本驱动的磁性随机路径生成方法：利用给定哈密顿量体系的小尺寸轨迹学习给定初态的条件随机演化，在同一体系、同边界协议的更大尺寸上，由路径潜变量生成有限时间未来，检验已支持范围内的时空统计。初态由指定构型、规则采样或文献准备流程提供，当前不学习其分布。网络不强制消费哈密顿量公式、交换常数或解析有效场；物理定义和参考参数仍完整存入配置供审计。

方法设计覆盖一维链、二维平面和三维体的分别训练，每个模型包固定各方向的边界设置，训练和大尺寸生成保持一致。首先验证同一物理时间窗内的尺寸推广；时间外推与文献长时寿命随后独立研究。当前Bauer开放链是首个案例，不限定方法最终只能用于它。

## 📥 用户输入与模型绑定信息

加载所研究体系的模型后，用户接口暂定为：

```text
model.generate(shape, temperature, seed, duration)

模型包示例（不同模型，不是同一模型的自由切换）：
1D开放链模型:       pbc=(False,)
2D周期平面模型:     pbc=(True,True)
3D全周期体模型:     pbc=(True,True,True)
```

此处是拟实现接口，尚不是可运行命令。shape须符合模型登记的空间维数，只改变各方向长度；所有维度中的自旋仍可为三分量向量。pbc从模型包读取并保持不变；旧接口若仍接收pbc，只用于一致性校验。temperature默认使用模型登记的约化温度theta；实际单位转换由配置层完成。

seed控制可复现的随机抽样，不作为具有物理意义的网络条件或预测特征。相同seed不能保证不同硬件位级相同，也不自动构成不同尺寸间的物理耦合。duration以约化时间指定总输出长度；块长和输出间隔绑定模型包，不以更改采样积分步数延长物理时间。逐块推进随机流而非重置seed，初态与路径流分离；恢复时保存状态、随机流、时间位置及必要缓存。

下列信息随模型包／配置绑定，无需用户每次输入：体系身份、晶格类型和基点、逐轴边界及其物理处理、易轴与坐标约定、固定相互作用及阻尼、初态准备协议、温度支持域、训练时间窗、输出物理时间网格及单位。仅有尺寸不能区分方格／蜂窝等不同晶格；默认由所加载的模型包解决该歧义。

输出至少包含spins、物理时间、自旋初态、温度、shape、pbc、模型／配置版本与随机流记录。一次调用可生成一条路径，多seed或已登记batch采样形成路径集合；统计分布通过该集合评估。

## 🎲 当前初态准备与路径生成

当前只要求训练条件路径生成器。初态来自已登记准备协议或显式输入，不要求另一个初态网络：

$$
S_0=\operatorname{Prepare}(a,\mathcal G,Z_0)\quad\text{或指定构型},\qquad
S_{1:F}=G_\phi(Z_p;S_0,\vartheta,\mathcal G).
$$

其中准备协议为$a$；确定性准备可以不使用$Z_0$。若准备含随机性，则初态随机流与路径潜变量$Z_p$分开。生成路径首帧等于实际$S_0$，flow运输时间不作为物理时间。上述为概念合同，不声称现有脚本具有同名API。

需要总体多初态统计时，应对同一已登记准备分布进行采样，不默认为自然平衡权重。若未来确有初态学习需求，再讨论两阶段分解、数据和四组验证；旧设计保留在[历史两阶段方案](INITIAL_STATE_PATH_PLAN_20260919.md)，不构成当前放行门槛。

## 🧩 一维、二维、三维及边界的统一设计

统一方法优先考虑显式邻接的局部模型或具有等价几何表达能力的网络。拓扑构造器由shape、pbc和模型包晶格定义生成邻接／位移／边界标记，不必向网络提供解析相互作用强度。

| 条件 | 实现与验证要求 |
| --- | --- |
| 一维链 | 开放端点缺邻居；周期方向才连接首尾 |
| 二维平面 | 两个方向分别处理周期性；保留边、角和内部环境 |
| 三维体 | 三方向独立周期标记；保留面、棱、角和内部环境 |
| 多基点／多子晶格 | 基点与位点类型由模型包登记，不能仅靠shape推断 |
| 周期几何 | 正确记录跨边界位移和邻居，不把所有对边点任意连接 |
| 很小格子 | 自邻接、重合邻居及键计数规则与参考Hamiltonian一致 |
| 变尺寸 | 空间归一化和聚合避免隐含训练尺寸；感受野与长程依赖单独核查 |

边界必须实际改变模型邻接／算子，不能只加一个标签而仍使用错误padding。跨维度会改变配位和局部环境；一维训练数据不能自动支持二维或三维推断。二维／三维中的旋转协变也须按自旋、易轴、空间位移及张量的正确联合变换核查。

## 🧠 通用方法与通用checkpoint的边界

本次冻结的是**同一方法可在不同磁性体系、不同空间维度上分别训练和生成**。第一层证据是在每个体系内用小尺寸训练、向更大尺寸生成；第二层证据是在1D、2D、3D案例中复用方法获得类似有效性。

不默认要求一个只用Bauer链训练的checkpoint零样本生成任意二维／三维磁体。若后续希望一个checkpoint联合多个体系，必须有体系身份或足够可识别的信息，否则相同温度、shape、pbc可能对应不同真实动力学。无需显式输入Hamiltonian公式，但也不能把不可区分的物理目标混在一起。

开放／周期边界固定于各自模型包。当前只做同一边界协议下的尺寸推广，不开展混合边界训练或跨边界外推；共同几何代码的复用不构成一个checkpoint支持多边界的研究目标。

## 🔬 必须分开完成的验证

1. 初态协议：核查指定／规则／文献准备流程、物理合法性、可复现性和局部状态覆盖；当前不要求认证一个学习式初态分布模型。
2. 条件路径：固定真实初态、多独立随机分支，比较增量、时空联合统计、局部机制和适用事件；防止总体初态混合掩盖条件误差。
3. 多初态使用流程：需要时在同一准备协议下比较模型与LLG的总体统计；学习初态模型对应的G/R、G/G四组验证暂缓，不作为当前必做项。
4. 尺寸：在同维度、同温度、同边界协议、同时间窗下扩大尺寸；跨边界外推不在当前范围。温度外推及维度外推不能由尺寸结果替代。
5. 方法通用性：依次完成1D、2D、3D的体系定义、数值参考与小到大测试，至少三个训练seed，不能由一种体系的结果替代另外两种。
6. 成本：初态采样、路径采样、真实数据、训练和验证共同计费；准确性与成本优势分别判定。

## 📋 执行顺序与当前状态

先冻结每个模型包的物理体系和初态准备协议、输出时间网格，再开展小体系条件路径受控比较及同边界尺寸推广。使用指定／规则／文献准备的初态，不接入新的学习式初态模块。二维、三维分别建立数据与验证，不一次性启动所有数据矩阵。

当前已完成的是单lag候选的有界开发实验；初态生成器、通用拓扑接口、二维／三维认证和端到端新模型均为计划。现有结果不证明准确短时路径、跨尺寸机制或加速已实现。本轮只冻结文档目标，新的数据量、准备协议、网络架构及计算预算尚需具体化。

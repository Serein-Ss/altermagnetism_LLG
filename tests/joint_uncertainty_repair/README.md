## 已确认的评估问题

原联合距离点估计采用无偏U统计量。双方有放回重采样整条独立分支后，bootstrap条件均值却是经验V统计量，与U相差

`mean(Dgg)/(n-1) + mean(Drr)/(m-1)`。

这是精确有限样本恒等式，已通过n=m=2的全部重采样枚举复现，不是仅凭点估计位于区间外判错。空间门控旧972项联合距离中，653项旧区间整体高于点估计，这只是发现线索。

实际例子：seed11原通路某L16开发状态点估计0.007502，旧100次区间[0.011049,0.023140]。精确重采样中心偏移0.008641。新99次预检的中心化近似区间[0.001287,0.012645]。仅作算法预检，不能当正式区间或达标证据。

## 修复方法与边界

- 保留原U点估计、不裁零；使用bootstrap U减经验V的误差分布，再围绕观测U反射分位数，得到中心化basic近似区间。
- 该区间只在非退化备择下作为近似；相等／近相等分布处未认证，不声称普遍95%覆盖。另报告999次完整轨迹标签置换的相等分布检验，含加一校正。
- 非拒绝不证明等价；原始逐状态p值未作多重比较，不用于整批验收／模型通过。没有降低物理标准。
- 整独立轨迹为重采样单位，双方误差都保留。格点、帧、相关快照不冒充独立样本。训练seed逐个列出；DEV反复使用，不是最终留出。

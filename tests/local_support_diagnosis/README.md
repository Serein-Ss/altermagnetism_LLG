## 本轮修补

补充旧聚合评估缺少的局域覆盖、逐格点条件均值误差、z/xy误差分解和分支采样噪声校正。它是评估证据链修补，不是已证实的网络修复。
复用全部9组最终90144步模型的保存结果，不修改模型、损失、数据或物理时间。
参考为72个DEV真实LLG快照，各128条独立0.1ps未来；每模型同样128条生成未来。
覆盖库是实际额外监督的两个TRAIN快照库共96快照、24父来源，仅L16；不代表全部native窗口训练覆盖。
开放链patch半径1、2、4，保持相同边缘掩码，不绕接、不镜像；整块绕登记z轴解析对齐，只消除公共方位相位，不做逐磁矩旋转。
这些构型距离不证明条件转移相同，不定义任意覆盖通过阈值。

采样校正的均值偏差平方为各分量平均的
`(mean_generated - mean_reference)^2 - var_generated/n_generated - var_reference/n_reference`。
两个条件未来集合独立；校正量允许负数，不开平方或裁零作为“无偏RMSE”。
base/fine差还包含各自分支采样噪声，不能当纯数值误差。
逐格点散点仅描述，不以格点当独立重复计算显著性；训练seed变化单列，旧DEV依然是开发证据。

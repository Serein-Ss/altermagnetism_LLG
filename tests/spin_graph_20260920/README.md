## 🎯 决策与实现

按[当前架构约定](../../GUIDE/MULTISCALE_STOCHASTIC_PATH_ARCHITECTURE.md#spin-graph-20260920)，使用磁矩专用SO(3)标量—向量消息传递。不是原版EGNN复现。固定格点，晶轴与磁矩联合旋转，叉积保留方向性向量表达，切向投影加球面采样保持磁矩模长。

`model.py`包含逐边学习消息、向量隐藏通道、逐节点通道归一化、每块温度／flow时间FiLM、逐节点时间注意力。物理时间作为独立输入。`cell_edges`保留开放缺邻居及周期镜像键的重数；checkpoint额外状态绑定逐轴边界。读取现有cell对象只使用拓扑，不读取哈密顿量参数或场。

```bash
bash ../run_zrs_mag.sh -m pytest tests/spin_graph_20260920/test_model.py tests/literature_path_campaign_20260920/test_models.py tests/literature_path_campaign_20260920/test_stream.py -q --junitxml=tests/spin_graph_20260920/logs/unit.xml
```

`smoke.py`拒绝覆盖已存在的smoke目录，保留原始结果。全部计算为zrs-mag CPU短测试，无GPU任务或正式重训。

## 📊 已完成的真实样本闭环

最终回归记录：新骨干7项加旧候选4项，共11项通过，用时4.05秒；存在旧绘图库的弃用警告，无测试失败。日志见`logs/unit.xml`。

来源为`tests/bauer_active_data_20260918/data/L16/train_parent14_base.h5`的两个训练分支，L=16开放链，63.82484966 K，1 ps共11帧，输出间隔0.1 ps；未使用开发或测试集。

宽16、深2，50次更新仅拟合一个固定flow插值小批次。温度输入采用明确的100 K数值尺度，不声称是训练集标准化或物理约化温度。生成4条路径、16个flow积分步，最大范数误差5.96e-8，首帧误差0；总测试约1.95秒，其中四条批量生成约0.092秒。这不是正式模型速度，也不能与真实LLG作同精度加速比较。

## ⚠️ 限制与后续

- 软件检查包括1D／2D／3D联合旋转、切向性、反向传播、周期平移、开放链反转、变尺寸调用、边界拒绝、checkpoint恢复及同seed重复／异seed差异。完整采样旋转测试必须共同旋转潜变量，不能只复用数值seed。
- 新骨干尚不包含完整多尺度层级，也没有方向性键位移编码；目前不能区分仅通过有向键几何区分的环境。二维DMI等体系正式训练前必须补齐晶格基矢、基点偏移和有向位移，并作对应测试。
- 本次多维测试使用合成小格子；实际训练冒烟仅Bauer。变尺寸可调用不意味着尺寸迁移准确。
- loss下降、范数正确和多样性存在不等于条件路径统计正确。必须继续做独立父状态、增量均值／协方差、时间与空间相关的受控评估。
- 未修改旧模型、旧权重、任务、主网页或远程仓库。该候选未经正式训练，不能用于文献结论复现。

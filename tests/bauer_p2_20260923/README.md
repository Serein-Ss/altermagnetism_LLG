## ⚙️ P1 冻结合同与实现

首轮 1 ps、11 帧、完整 L16/L25/L32。训练集 1 ps 的平均平方位移分布最小约0.357、中位约0.672、最大约2.038，窗口包含明显演化，并非人为压成静止任务。复用既有同长度闭环，便于比较模型而不同时改变物理窗口。

图骨干宽64、深3、逐点 LayerNorm、块内标量时间注意力、FiLM、联合旋转协变向量输出和球面采样。温度由所有训练数据均为同值的审计确定，均值为该值、常量条件尺度置1；归一化输入为零。J、K、阻尼不作为本单体系模型的可变输入，能量只用于评估，损失仅 FM。

训练 batch=8，6000次更新，lr=0.001，seed=11/22/33。半数窗口从原始父状态开始，半数从原始轨迹内均匀截取；截窗不跨越原始 split。加载器按需读取 H5，每个 batch 同尺寸，不统一空间裁剪。

开发集每1000步评估一次：按条件增量协方差的逐父状态 RMSE 均值选模，能量均值误差仅打破完全相同的主指标值。该规则是本轮开发决策，不是有物理意义的综合认证分数；其他分项可能仍然失败。

接续接口只验证工程行为：末态传递、新随机抽样、边界帧去重和完整块边界的 RNG 恢复。部分末块只返回需要的前缀，并明确不可用仅末态/RNG无损续接（需保留未用尾帧）。非网格终点拒绝；本轮不训练/认证长时接续。

[logs/tests.log](logs/tests.log) 包括能量/梯度、球面近退化、条件域拒绝、checkpoint、同随机流恢复、联合旋转以及临时合成数据的完整报告绘制测试。合成测试不进入研究结果目录。

## 📊 P2 交付与看图

每个训练种子保存 best/last checkpoint、优化器及随机状态、配置/代码哈希、开发选模记录；完成后对开发与历史诊断父状态各生成16分支，分别用16/32/64/128 flow步。所有生成轨迹保存 NPZ；每一条都是1 ps，flow步数不改变物理时长。

主要统计：磁化均值/方差，物理能量均值/方差，初态重叠，0.1/0.2/0.5 ps 时间滞后点积，1/2/4格点空间点积，逐时刻逐格点条件增量均值与无偏分支协方差。每个父状态单独比较，格点与帧不作为独立重复。

128步报告包含固定父状态、独立整条分支 bootstrap（生成和参考分别重采样，400次）。图中的区间是点态区间，不是同时区间；有符号平均可能抵消，因此同时保留完整指标张量误差的 RMSE。无共同训练seed误差与分支误差混算，无未确认事件规则。

## 上轮及本轮确认

连续轴向gauge2结构操作误差降至约2.3e-7；相对同期control，三seed描述性平均的完整1ps增量方差、两时刻关联、能量误差约下降4.4%、6.5%、6.7%，联合路径距离下降约32%。但0.1ps条件均值及联合构型距离分别略差约0.9%、1.6%，不同seed和尺寸也非一致改善，因此未完成物理闭环。

本轮冻结三个gauge2模型，用48个TRAIN来源状态各3个运输时刻检查：只反转格点顺序，不改变三维磁矩分量，输出逆置换后与原输出比较。最大相对RMS差：seed11为0.646747、seed22为0.545065、seed33为0.435944，见initial_probe.json。探针是结构检查，不是这些构型的LLG误差，也不是唯一病因证明。

当前Bauer无场、同质最近邻交换+单轴各向异性、等价左右开放端点，Hamiltonian及其梯度满足该编号置换。它不是空间镜像下磁轴向量的变换，不向DMI、非等价边界或其他模型套用。

## 最小有依据的干预

在gauge2上平均两种编号的共享运输速度，逆置换后合并。控制组保留原gauge2速度不变。没有增加参数，不平均最终路径，不输入解析场或Hamiltonian系数，不消费干净未来。两端各两个初态锚点均须在gauge支持域；不足则明确拒绝。当前原始库审计涵盖相关重复，不当作独立样本数；接续状态逐次检查。

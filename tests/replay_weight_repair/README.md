## 候选修复与控制

问题：广泛native窗口具备局域相似构型，但训练还对两个稀疏快照库进行每更新48例额外监督。native batch8与extra batch48分别平均，所以6倍例数不等于6倍损失或梯度；不能把这个比例直接当病因。
检验额外监督权重1、0.25、0，三seed11/22/33，每组都从对应90144步FM控制组开始。相同原始窗口、t0扩充分支、50%真实/50%刷新模型状态extra、经验teacher、随机流和6000更新。模型和Hamiltonian/物理lag/数据划分不变。重置Adam、200步热身3e-4后余弦9e-6，clip10，固定最终96144。

所有组均计算相同未加权额外梯度，再按权重加到native梯度。零权重组仍付这部分诊断计算成本，不称优化后的最快native-only配方。初步诊断/每128更新记录梯度范数、夹角和加权比例；首步原始梯度要配对相同。负夹角不自动证明干扰有害，更不能代替物理改善证据。
旧balanced_replay检验较早checkpoint下采样密度与平衡，本轮检验当前teacher/model-state配方中的标量权重；保留旧结果，不声称全新未做过的思路。

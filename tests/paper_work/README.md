当前最重要的结论：

- **短时统计有一定一致性，但不是完整认证**：在间隔0.01和窗口0.08下，当前候选的若干描述性误差与两种独立参考方法间的差异接近。

- **状态覆盖存在风险**：本报告六维局部描述符近邻分析提示开发/长滚动参考状态与训练样本有明显距离。该诊断不能证明因果，也不构成充分覆盖证书。
- **反向首达没有得到有效验证**：主事件规则下各方法B首达均为0；六个畴壁起点的所有参考分支到时间8仍未达到A/B核心。不能用“都没有翻转”证明翻转概率正确。
- **文献级生成与计算收益未实现证明**：存在历史L100真实LLG长时结果，但没有当前冻结模型匹配的L100寿命/长度/温度标度结果；记录的推断成本也不支持直接宣称加速。

本轮只读原始数据，没有重训、补模拟、改模型、改参考阈值合同或提交服务器任务。历史实验协议不同，不为增加样本数而混合。

训练集：768条保留路径 + 768条覆盖扩展路径 = 1536条噪声路径。每条路径长度0.08、33帧，每4个保存步截取一个0.01转移，得到8对，共 **12288对**。每个温度6144对；L=25、theta=0.11/0.13、K/J=0.1、lambda=0.1、开放边界、无外场。

开发集也是1536条路径、12288对，但来自不同的原型parent。数量相等只是该原型的设计，不是训练/验证必须相等。

历史起点继续追溯到 `data/research/runs/bauer_first_loop/20260913_v1/development.npz`。不要被文件名误导：其内部同时有 `train`、`condition`、`development`、`development_condition`。短转移构建器只从内部 `train` 取起点，之后在这些父轨迹之间进一步划分本轮原型train/development。

精确到每一对样本的文件、路径索引、噪声种子、开始/结束帧、温度和来源族，见 [T01_transition_index.csv](tables/T01_transition_index.csv)。这张表可以直接回答“这个样本到底从哪里来”。

## 🔍 训练集、验证集、测试集有什么不同

区别首先是**用途和信息隔离**，而不是一定来自不同哈密顿量。

| 数据 | 能做什么 | 不能做什么 |
| --- | --- | --- |
| 训练集 | 优化网络参数；估计输入标准化与训练噪声尺度 | 不能单独证明泛化 |
| 开发验证集 | 比较候选、训练预算、采样步数、模型结构和指标 | 一旦用于选择，就不能再称未揭盲最终测试 |
| 最终测试集 | 模型与评估规则冻结后，独立确认物理结果 | 不能反复据其结果调参后仍保留“独立最终测试”称谓 |

本次核对的原型train parent为0、96；development parent为16、112；训练/开发噪声种子交集为0。来自同一父轨迹的不同截窗不应随机分到不同集合。扩展覆盖族另有独立来源命名，不能仅比较一个数字family编号就判断重合。[划分审计](source_data/split_audit.json)

但这不代表现有开发集足够全面：原型development只有2个父轨迹来源，且没有自动覆盖当前扩展训练集的全部状态类型。旧24条件库和新12起点库用于补充诊断，经过反复开发讨论后，都不能充当最终保留测试集。

### 当前实际上怎样选择checkpoint

当前是固定24000次更新后的最终EMA参数，**没有逐checkpoint验证曲线，也没有验证集最优checkpoint选择记录**。S04A只能说明训练过程，不能证明选型合理。

S04B/C展示已有的历史6000/24000预算对照：原型开发集末时均值场RMSE的描述性均值由0.00679降到0.00366，键关联RMSE由0.00564降到0.00239。这支持当时增加预算改善某些短时指标；不是当前覆盖增强模型已通过最终测试，也不是纯更新次数的因果对照，因为余弦学习率日程也改变。

后续合理选型方式：预先登记候选checkpoint与同初态参考分支，固定采样设置，在开发集上同时比较局部增量、均值/方差、空间关联、滚动稳定性、事件概率和成本。保存每个checkpoint的完整指标表；按照预先设定的物理容差筛选，再在合格候选中比较误差和成本，不事后拼一个有利总分。三个训练种子用于报告稳定性，不只挑最好看的种子。

## 📊 怎样判断是否学到局部随机演化

固定完整初态x，只改变未来噪声；比较真实参考和生成模型的短时间球面增量。

令 `v = Log_x(s(t+Delta))`，本报告固定Delta=0.01：

| 指标 | 意义 | 图中希望看到什么 | 不能单独证明什么 |
| --- | --- | --- | --- |
| `E[v]/Delta` 的误差 | 条件平均运动方向与幅度 | 与参考差异接近独立参考差异，并有足够样本精度 | 无限小步长漂移已学对 |
| 切空间方差迹比 | 热涨落总强度 | 接近1，而非0或异常放大 | 非高斯形状和空间关联正确 |
| 完整增量协方差误差 | 不同格点和分量的联合涨落 | 随参考样本增加保持可接受 | 有限样本矩阵误差等于物理偏差 |
| 逐格点/分量W1距离 | 增量边缘分布差异 | 较小且无系统性状态依赖 | 完整联合路径分布一致 |
| 多步均值、键关联、时间协方差 | 短转移反复作用后的结果 | 误差不异常累积，多个种子稳定 | 任意长时间仍可信 |

对应S02、图2、图3。当前S02各候选切空间方差迹比的12状态平均约0.984–1.000；均值增量和协方差误差也接近Heun–MT对照。但只有128条分支，完整75维增量协方差的参考间相对误差也约0.765，不能把“与这一噪声底相近”写成高精度等效性。

这里的参考数值误差和抽样误差尚未完全分离。例如部分起点的Heun与MT首达A概率也存在差异；不能把所有候选—参考差异都归因于网络。

## 📈 训练状态是否覆盖足够

S01使用了两层检查：

1. 链级投影：磁化Mz、最近邻关联；局部sz直方图。看有没有只包含一个磁盆、缺少不均匀状态等明显空白。
2. 局部六维描述符：中心sz、左右邻键点积、左右邻居sz、`cross(s,left+right)_z`。标准化只拟合训练池；同一噪声路径的所有窗口一起划分，用训练留出路径距离的99%分位数作提示线。

| 数据 | 超出该训练近邻提示线的描述符比例 |
| --- | ---: |
| 训练留出路径 | 1.00%（按定义） |
| 原型开发集 | 39.84% |
| 新参考分支t=0.01 | 41.80% |
| 新参考分支t=0.08 | 42.56% |
| 新参考分支t=0.8 | 47.24% |
| 新参考分支t=8 | 58.92% |

这些比例是**本次六维描述符与有限近邻池下的经验诊断**，不是未覆盖物理状态空间的体积比例；格点/窗口也不是独立样本，故不绘制伪二项置信区间。低维投影重合也不保证完整状态或转移规律覆盖。

还需要检查不同边界位置、温度、磁盆/壁状态、局部曲率等分组；把开发误差与描述符距离联系；有针对性补参考标签后进行受控比较，才能确认覆盖是否是误差原因。当前只有两个温度，不能证明连续温度或其他阻尼条件推广。

## 🧪 两种基线到底是什么

### 简单随机基线：不是随便加白噪声

它也只从相同的12288个训练转移学习，不读取开发标签来拟合。对每个训练温度，先将目标变换成球面切向增量，再拟合4个局部基函数的线性系数和一个噪声尺度：

- 邻居和的切向投影
- 自旋与上述投影的叉乘
- 易轴director项的切向投影
- 自旋与该易轴项的叉乘

预测时，局部平均切向位移加切向各向同性高斯随机量，再通过球面指数映射返回单位球面。因此它能生成条件随机分支，但分布族比流模型受限。

它没有直接加载J、K、lambda的解析力系数，但基函数本身带有较强的局部相互作用/易轴结构先验。不能称为完全无物理信息的黑箱。参数见 `tests/output/sample_tangent_baseline/model.json`；定义见 [sample_tangent_baseline.py](../experiments/sample_tangent_baseline.py)。

比较它的意义：复杂流模型是否比简单、可解释且数据拟合的随机转移更准确或更高效？如果没有，应保留这一不利结果；基线也可能提示哪些物理结构值得学习。

### 确定性基线：每个完整输入只有一个未来

旧first-loop有与当时RFM共享骨干的确定性模型：`output/bauer_first_loop/20260913_v1/deterministic_{11,22,33}.pt`。训练目标是预测轨迹的误差，没有生成潜变量。相同初态和条件重复16次，输出相同路径，条件分布退化为单点。

它不是“把真实LLG温度改成0”，也不是“三个训练种子就是三次热涨落”。其作用是比较均值预测能力，并展示为什么一个确定性输出不足以表达随机路径分布。

旧结果有4个初态×16分支，S05先在各初态内部算方差，再汇总；绝不把初态差异当热噪声。它属于历史协议，与当前局部流的训练数据、预算和时长不同，因此单列，不放进当前六方法的公平排名。当前同预算同骨干确定性对照仍待补齐。

与文献的对应不是“每个ML指标都必须在原文找到一条曲线”。局部增量/分布距离是检验替代模拟器的新诊断；最终的机制和寿命再与文献物理结论对应。Bauer原文图2是Mz(t)和格点—时间演化；图3是寿命随长度；图1是能垒随长度。原文图4涉及不同各向异性条件，不能直接由当前单轴K/J=0.1数据复现。附录A计算连续翻转间隔均值，不等同首次首达生存函数。[^1]

详细对应见 [T10_literature_mapping.csv](tables/T10_literature_mapping.csv)。原文图3对其中一组寿命做了显示倍率，后续提取曲线需恢复原尺度。此图包没有捏造文献数字化数据点。

## 📋 当前交付与边界

这是一次**探索性补全**：让缺失的对照、选模、尺寸/时间测试、事件分析和计时真正具有执行入口及原始数据来源。实验成功退出不等于模型通过科学检验。新结果完成后从本目录 `index.html` 查看，静态图只生成 PNG；旧图仍在上级 `index.html`。

完整文献时长 `750000` 尚不属于自动提交的有界任务：当前一步代表约化时间 `0.01`，需要 `75000000` 次物理转移。先由同 GPU 计时估算预算，再由用户批准长时执行；绝不把 `200` 的结果命名为文献长时复现。

## ⚙️ 预先固定的实验

| 内容 | 配置 | 用途 |
| --- | --- | --- |
| 小体系训练 | 原有 L25，384/768/1536 条轨迹 | 数据效率，分别为 3072/6144/12288 个转移对 |
| 重复训练 | 每档 flow 三个种子；全数据确定性三个种子 | 共 12 个训练实验 |
| 公平约束 | 相同骨干、24000 更新、batch128、EMA | 相同更新预算，不等于相同 FLOPs 或时间 |
| 划分 | 源文件内按完整噪声轨迹嵌套抽样 | 同一路径八个窗口不拆分 |
| 验证集选模 | 每 6000 步，六个开发初态，64 次生成 | 按 0.08 终态完整自旋向量的有偏样本 energy distance 平均值选最小 |
| 测试初态 | L25/50/100，各两温度×三类初态 | 共 18 个事先指定的扰动初态 |
| 三类初态 | 近正向、倾斜、中心畴壁 | 不是热化后的自然占据概率样本 |
| 普通路径 | 每初态64条，约化时长32 | MT/Heun/旧flow/新选定flow/确定性/Gaussian |
| 延长路径 | L25/L100 两温度的畴壁初态，时长200 | 事件与空间机制；不能保证出现反转 |
| 参考数值对照 | MT、Heun 步长0.00125；L25补0.000625 MT到8 | 不能将两个有限样本差异直接当解析误差 |
| 磁盆校准 | 六组 L/温度，MT时长200、64条、半正半负 | 150–200尾窗的正/负侧分位数，仅经验磁盆核心 |
| 物理条件 | 开边界、J=1、K=0.1、阻尼0.1、温度0.11/0.13 | 模型从样本学习，不输入解析力系数 |
| GPU计时 | 同分配、L25/50/100、batch1/64/128 | 丢弃预热；MT float64 vs flow float32，精度分别报告 |

训练子集只取原训练数据。开发集沿用既有家庭隔离划分，但仍有历史训练容器来源，不能包装成最终外部独立检验。新测试初态及其参考噪声未参加选模；所有训练种子的短时测试保留，不能事后只报告最好测试分数。最终主展示的全数据新模型按开发分数选择，旧 seed22 作为冻结对照保留。

样本数是预算限制下的诊断数量，不是已证明足够的统计功效。对固定初态的64条随机路径，二项概率接近0.5时 Wilson 95% 半宽约0.119；零事件时上限约0.0566。不同初态不能当作同分布样本混合，时间帧不能当作独立样本。确定性模型重复64次没有64个独立随机重复，其事件概率不画虚假的二项置信区间。

## 📦 文件与执行

| 路径 | 作用 |
| --- | --- |
| `config.yaml`、`manifest.json` | 参数、任务矩阵、训练子集索引和输入哈希 |
| `run.py` | 训练、参考模拟、生成、基线及计时 |
| `analyze.py` | 所有结果成功后构建 PNG/CSV/独立 HTML |
| `test_completion.py` | 小规模单元和接口测试 |
| `gpu.sbatch`、`cpu.sbatch` | rtx4090/fat 提交入口；任务名称 zrs-mag |
| `submit.py`、`submission.json` | 一次性提交及依赖记录；不监控 |
| `data/` | 本次原始测试轨迹，不能冒充正式训练集 |
| `output/` | 每6000步checkpoint及开发集选定模型 |
| `results/`、`tables/`、`figures/` | 机器报告、源数据表、PNG |
| `logs/` | CPU/GPU输出、单元测试报告 |
| `long_rollout.py` | 需预算批准才运行的长时分块续跑入口 |

GPU冒烟测试通过后才启动新训练和模型生成；正式生成还依赖全部训练成功。参考模拟独立在 fat 运行。汇总分析依赖全部计算成功，失败不会用空值伪装为完成。没有人为设置数组最多两个并发，实际并发由 Slurm 分配决定。再次提交前需检查 `submission.json`，不得重复启动整个实验。

长时脚本每块200约化时间、保存间隔0.1，持久化自旋状态和随机生成器状态；重启只重算未提交完整标记的块，不重新抽取已完成部分。当前冻结旧flow22为该脚本对象，不自动把新模型替换进去。块边界的精确重放在相同软件/设备条件下测试；跨 GPU 位级一致性不作保证。已提交的有界任务不会调用此长时入口。

## 🔍 验证记录与方法约束

单元测试检查完整轨迹嵌套子集、分布距离、不同长度和确定性重复、随机状态分块重放、Torch MT 与 CPU MT 给定相同抽样的一步一致，以及事件时序/未决处理。结果写入 `logs/preflight.xml`。GPU冒烟另写 `results/smoke.json`，不能用 CPU 测试代替 GPU 可用性确认。

采用 Karpathy Guidelines 限制修改范围；experimental-design 固定分组及选择规则；statistical-power 用于说明预算下的精度限制，不宣称功效达标；scientific-visualization 保留原始路径、缺失证据和 PNG 源表；markdown-mermaid-writing 组织本说明。相关技能软件来源沿用[上级图包记录](../README.md)。这些工具不构成物理或统计认证。

## 本轮候选是什么

仅对已审计无外场、交换＋单轴各向异性的Bauer开放链使用。该Hamiltonian在固定易轴下具有绕易轴的自旋旋转对称性；这与任意自旋旋转、联合spin/crystal SO3或反射不同。

用实际初态第0、1格点的横向磁矩各定义一个移动坐标系，将当前flow草稿和初态一起旋到该坐标系，调用共享原骨干，再将切向输出旋回。按两个格点横向磁矩模长平方加权两个输出。两个角度随初态转动，因此能够实现连续轴向协变，不是两个固定角度的C2投影，不是平均最终物理轨迹。没有输入干净未来、解析有效场或Hamiltonian系数，没有新增可训练参数。

不采用argmax选方向，避免坐标切换跳变。单个格点横向为零时，其分支权重为零。两点总横向权重≤1e-12时明确拒绝该初态；纯极向起点不在当前候选支持域，不静默回退。接近奇异构型仍可能敏感，接口拒绝／适用域和成本必须披露。不能向DMI、横向场或一般磁性体系强加这一Bauer特有对称性。

这个坐标接口使用固定边界格点，不保证链反转／平移等额外性质；没有宣称完整多尺度迁移或跨体系通用性。有限步MT离散噪声参考可能有轴向各向异性，独立base/fine比较继续保留。

本文件保存待启动分支，不构成当前数据规模或实现要求。先完成经典及交错磁主线，各分支再单独确定研究范围、误差容差、资源和合同；已授权的独立文献复现按其原条件继续管理。

## 1. 长时、多lag与混合方法

固定窗口先闭合，再分别测试多lag、末帧锚定chunk和混合算法。每段存初态哈希与独立潜变量；完整状态的马尔可夫假设须成立，有记忆热浴/隐变量则扩展状态。

CK比较直接2lag与两次lag组合并对照真实LLG，以冻结条件状态/特征测试；不能假定低维序参量本身严格马尔可夫。段界、能量分布、ACF、谱、转移和生存都检查；采样步数、chunk长度、保存频率分别收敛。固定F扩大lag会丢高频与短事件，不能同时承诺保留它们。

`T_valid(condition,observable,tolerance)` 是预注册检查时刻中连续通过范围的最大终点，报告时间分辨率和未测区间，不给无条件全局保证。100–10000个滚动窗口只是候选，数量不证明稳定。

少量高精度LLG从当前生成分布继续演化，不保证消除先前偏差；球面投影只保证几何。混合算法单独认证，不替纯生成器背书。平衡MCMC接受率校正不能直接赋予链步真实物理时间。

固定窗口准确性、方法比较和成本的三类结论分别报告，成本公式见主协议5.4。长时扩展的误差与成本重新认证，不沿用单窗口加速比。

## 2. DMI与阻挫

DMI扩展采用定向键 `h_DMI=sum d_ij dot (S_i cross S_j)`，登记d_ji=-d_ij、计数、方向和负梯度检查。J1–J2也登记有符号权重；多个交换常数不证明阻挫，需具体竞争几何、基态和结构因子证据。独立DMI、独立阻挫之后再做联合挑战，不把这些项添加成Gomonay原模型的隐含成分。

## 3. SOT脉冲路径

**状态为deferred / implementation_enabled=false，仅为研究状态标记，不是现有配置开关。此规划不启动SOT实现或计算。** 历史驱动数据保留原有来源标签，不自动进入本分支。主线零场合同继续强制SOT/STT/电流为零；完成经典及交错磁主线认证后再单独决定启动范围和资源。

研究问题：给定完整初态、热浴和SOT脉冲协议，能否学习脉冲作用与撤除后弛豫的条件路径分布，正确预测反转概率、时间、返回和多稳态占据，并区分热噪声放大、初态敏感性与确定性混沌？不预设交错磁必然具有更多分支或更快反转。

**文献先行。** [Cao2026]使用VAMPIRE研究SOT驱动交错磁，报告切换时间、脉冲后混沌弛豫及周期脉冲多状态响应。启动前核查全文、补充材料及可用代码/数据，记录交换模型、各向异性、尺寸、边界、温度、初态、脉冲、力矩和Lyapunov估计条件；修订3仅记录已核实发表信息及摘要结论，修订4未补充全文核验，未把其“随机切换”认定为固定初态独立热噪声路径分布。若模型不同，单独复现其原条件；不能将其参数直接拼入Gomonay模型并声称文献一致。

**方程合同。** 在实际Gilbert/LL约定下推导阻尼型与场型SOT，登记极化方向、叉乘顺序、符号、量纲、转换中的alpha项及角动量来源。说明两子晶格受到同号、交错或不等强度的力矩及依据；电流到力矩的换算需有材料参数，不齐全时只报约化力矩。不得把SOT写成热噪声或Zeeman场的隐含替代。需要脉冲时间函数的非自治路径生成条件，不能仅用一个静态电流标量代表整个协议。

| 子阶段 | 工作和必要证据 |
|---|---|
| S0 文献复现 | 先核查并复现所选论文的确定性轨迹、切换阈值/时间及撤脉冲弛豫；仅复现实际使用的温度与驱动条件 |
| S1 零温控制 | 固定初态与脉冲，多次运行应在数值容差内一致；另用明确微小初态扰动研究敏感性。正Lyapunov需切向动力学或收敛的重归一化估计，不能由两条有限温路径分离推断 |
| S2 有限温先导 | 同一完整初态、同一脉冲，仅改变未来热噪声；保留成功、失败、返回及未决路径。先确认可重复的分支概率和观察窗口，再冻结数据条件 |
| S3 最小数据矩阵 | 首先选择一种有文献依据的力矩和单脉冲，在阈值附近有限扫描幅值/时宽及少量温度；初态、窗口、重复数由功效冻结，不同时铺开所有极化与波形 |
| S4 模型验证 | 零驱动对照、相同条件随机LLG底线和匹配预算学习基线；独立初态及预选脉冲条件留出；比较完整路径分布、反转概率、生存/RMST、返回率与末态占据 |
| S5 可选扩展 | 单脉冲通过后再研究周期脉冲、多稳态和记忆；连续脉冲共享历史，不能把每次脉冲当作独立重复 |

每条路径额外保存驱动protocol_id、全脉冲时间表、极化、场型/阻尼型系数、子晶格作用规则、开关时刻及撤脉冲后窗口。分割仍按初态来源与父轨迹，脉冲幅值/时宽的泛化条件预先留出。跨窗口续接须携带绝对驱动时间或脉冲相位。

主指标必须区分脉冲内越零、撤脉冲后的稳定反转和再次返回；阈值、驻留时间及删失规则冻结。数据必须保留自然概率，不通过筛选或强制类别平衡修改评价分布；若训练重采样，记录并检验概率校准。驱动中不使用能量单调下降/守恒验收；仅在明确热与功约定后分析能量收支，电学功耗不能由磁能差替代。资源、误差容差及启动决策另立SOT合同，当前无该合同、无执行授权。

## 3. 文献参数、约化内核与旧生成器接口

### 3.1 先核实模型身份

- Gomonay 按正式补充材料逐项定位 Hamiltonian、LLG、色散、静态/运动壁公式。本轮已有实现标注 S1/S44/S7b/S9；旧 GUIDE 的 S8/S9 等编号有冲突，必须通过原文建立 equation_map，不能盲抄编号。
- 核查 J1/J2/J_tilde 的键类型、符号、重复计数、子晶格偏移，以及 K_SW=0 与 K_DW=0.047 meV 的不同任务用途。新增有序态无场数据使用审定后的有各向异性模型，不得误用无各向异性色散配置来推定同一个有限温相变。
- 校验 100/110 晶胞变换、每胞磁矩数、物理盒长、边界和波矢单位。相同自旋总数不等于相同几何尺寸。
- 明确参考磁矩、gamma、a0 与来源，独立计算 E0、t0、B0、温度转换。缺乏审定换算时只报告约化量，不能擅自标 ps/K。

### 3.2 统一真正用于生成的物理实现

当前 `scripts/generation/generate_v3_gomonay_shard.py` 仍依赖旧 `UnifiedLLGSolver`，不得宣称自动继承 `scripts/core/reduced_llg.py` 和新 `DoubleLayer` 的认证。

优先为已认证约化内核增加专用无场路径入口，复用按 paper_id 的参数与几何；在原有责任目录中实现，不复制第二份 Hamiltonian。需兼容轨迹级 RNG、流式保存、事件后处理和模型 loader。

旧 V2 仅作历史开发数据。若要复用旧生成器，先通过单位换算后的逐项能量/有效场、确定性动态、平衡统计及随机弱收敛对照；发现不一致时解释原因并生成新数据，不把新求解器证书套给旧文件。

### 3.3 共用强制检查

- 双精度随机构型的逐项有效场对独立能量负梯度：继承旧 GUIDE 的 1e-10 相对/近零绝对门槛；分别覆盖开放、周期、混合边界。
- T=0 无驱动：正/负 Néel 基态稳定且等能；阻尼降低能量；无阻尼能量漂移随 dt 检查，达到舍入误差时如实说明不可拟合阶数。
- 对实际求解器噪声接口检查至少 10^6 分量的均值、方差、跨分量/位点/步独立性、dt 缩放、种子重放及 T=0。
- predictor/corrector 共享同一步随机增量；保存预测步与最终投影前误差，并与几何积分器检查平衡观测量。归一化后模长正常不能单独通过。
- 对相互作用 Gomonay 模型做 dt、dt/2、dt/4 和独立热平衡检查。Nishino 通过只证明自由磁矩基准范围，不能自动覆盖相互作用体系。
- 旧测试中若存在镜像实现的自证，补独立小格点/解析/Monte Carlo 平衡对照。Monte Carlo 仅认证静态分布或准备样本，不代替 LLG 的物理时间。

## 4. P2：Gomonay 文献复现补全

### 4.1 独立参考与容差

先创建 `reference/target_registry.json`：逐图逐量记录 DOI、正式版本/勘误、页码、单位、原始/数字化数据、数字化误差、公式及参数映射。独立实现参考解析式或使用文献数字化点，禁止将模型自己的 dispersion 输出称为外部真值。

每项量在新验证运行前注册容差与误差模型。容差应有文献精度和研究用途依据；数字化误差超过科学目标时应提高参考质量或标 inconclusive，不能扩大容差直至当前偏差通过。已查看的旧批次只作探索；最终判定使用冻结规则后的新独立验证批次。

### 4.2 色散 Fig.2 / S2

- 核对论文 500×500 的物理计数定义及实现映射；执行原条件或明确论证等效性，不将 32/64/96 小尺寸扫描称为原尺寸复现。
- 覆盖高对称路径与多个角度、正负频率和两子晶格/圆偏振通道；量化两支频率、Delta omega、节点及 C4 变号。保留 J_tilde=0 消融。
- 使用 dt、dt/2、dt/4 与至少三个频谱窗口；核查 Nyquist、频率格宽、激励覆盖、峰拟合及不确定度。多个结果落在同一 FFT 格不等于连续频率误差为零。
- 全部模式及强度入表；可将未激发点标为不可识别，不能事后筛掉误差大的模式再宣布通过。
- 本任务的 sinc 激励仅用于频谱测量，不进入无场训练路径。

### 4.3 静态壁 Fig.3 / S4

- 核查原文 10000×30 长条与旋转超晶胞的实际盒长；长边开放、短边周期，依文献弛豫。记录边界约束，禁止靠不相容周期接缝维持倾斜壁。
- 至少复现 100 与 110 方向，并按文献目标补角度依赖；两子晶格先插值到共同物理坐标，再算 n、m。
- 同时比较 n_z、m_z 的全剖面、子晶格壁宽、局部磁化的符号/幅度及晶向变化。只匹配一个 tanh 壁宽不足以通过。
- 能量、残余力矩、位置、宽度和剖面的长时变化均需满足预注册稳态容差；增加长条尺寸和弛豫时间排除边界/瞬态误差。

### 4.4 动态壁 Fig.5 / S5

- 先审计原文实际运动制备及后续演化定义，按正式补充材料复现；不能将当前 velocity=0.5 的自由运动点称为受驱动稳态，也不擅自增加 SOT。
- 扫描原文指定的交错交换强度、晶向和速度范围，覆盖阈值上下；测定位置、速度、宽度、相位、面外形变和内部振荡频率。
- 使用能分辨多个周期且能检验稳定性的长时间窗；结合拟合不确定度与 dt/尺寸收敛判定临界行为。
- 数值不支持某个原文目标时保留 fail/inconclusive，不从单一近匀速轨迹外推整条临界曲线。

### 4.5 明确完整性边界

旧 GUIDE 的既定 Gomonay 任务为 Fig.2/3/5 及相关补充图，不包含重做 DFT。Fig.4 磁针操控在本轮无外场扩展范围之外，登记为 not_in_scope，禁止宣称“整篇所有结果完全复现”。如原文某图含 DFT，只复现本项目明确承担的原子/连续模型部分。

P2 通过仅表示注册的文献目标对应；有限温随机路径必须继续通过 P3/P4，不能由零温色散或壁动力学推导其自动正确。

## 6. P3：无场平衡温区与初态池

### 6.1 先测当前模型，不能套实验 T_N

固定审定 Hamiltonian、各向异性、边界、阻尼和无场条件，初始候选尺寸为 L16/32/48/64/96/128，L 指明为未旋转原胞边长；旋转几何另记基矢/物理长度。此为本项目设计，不是论文冻结参数。

- L16/32 用于软件与局域涨落；L48/64 是机制训练候选；L96/128 预留大尺寸评估。是否容纳机制由数据决定。
- 首先做宽温区约化温度扫描，覆盖有序到失序；用正向、负向和随机等分散初态至少四条独立平衡链。
- 测量总能量、|n|、n_z、n_z²、n_z⁴、磁化率、热容、结构因子与空间相关。Binder 定义需根据所选标量/矢量序参量明确写出。
- 对相关时间序列计算积分自相关时间、有效样本数、rank/folded split Rhat；signed n_z 与盆内偶观测量分别报告。不能用不跨盆的正负链要求全局 signed 混合后再误判局域平衡。
- 盆内平衡的项目默认检查为 Rhat<=1.01、关键观测量 bulk/tail ESS>=1000，且多个独立时间块无超过预注册物理容差的漂移。这些是最低诊断条件，不代替独立静态分布对照。
- 在转变区细化网格，用独立链/时间块 bootstrap 估计 Binder 交点及有限尺寸趋势。区分 T_N(L) 赝临界尺度与热力学极限估计；交点证据不足时仅报告有序温区，不发明 T_N。

若用 T/T_N 设计温区，T_N 必须来自已冻结的独立校准；同一个尺寸泛化测试组使用相同绝对温度，不能按每个 L 的 T_N(L) 偷换条件。大尺寸平衡校准数据与最终动态测试路径分开，不参与模型选择。

### 6.2 训练初态的统计身份

- 从认证的盆内平衡链提取去相关完整构型；采样间隔至少 5 倍相关观测量最大 tau_int，并验证残余相关，不能只靠间隔数值保证独立。
- 记录 parent_chain_id、initial_state_id、盆地、时间索引、准备温度、谱/相关统计和哈希。来自同一相关链段的构型组成同一划分组。
- 正/负盆平衡混合、指定盆条件分布及预制畴壁三者分开标记；若制备 50:50 正负盆初态，明确这是设计分布，不冒充自然平衡权重。
- 预制壁可作为单独的有限温纹理演化任务，但不计为均匀初态下的自发成核；不能通过播种壁来制造“无场自发翻转”。

## 7. P4：足够长的无场轨迹与事件统计

### 7.1 长度不是预设 1/3/8 ps，也不是等待所有路径翻转

每个温度/尺寸先运行独立 pilot，至少 128 条路径，并覆盖最慢条件和最大尺寸；用冻结的倍增窗口延长，例如 tau_obs、2tau_obs、4tau_obs。起始 tau_obs 根据实测相关时间与初步动力学确定，转换到 ps 必须有单位证据。

长时要求分开处理：

1. **准备充分**：平衡链已通过 P3；不能把最初瞬态当平衡涨落。
2. **结构/路径充分**：至少覆盖最大相关时间的多个倍数，比较延长窗口后的空间统计、事件识别和驻留行为。
3. **翻转统计充分**：对于声明估计寿命/稀有机制的条件，事件数和置信区间必须支持目标精度；低温大尺寸无事件时不能假定延长少量时间就足够。

默认有限时域路径观察窗口候选不少于关键观测量最大 tau_int 的 50 倍，末段稳态诊断窗口不少于 10 倍；这些是项目设计下限，需要以实际时长敏感性验证，不能当普适物理常数。

对定长时间窗概率 P(event before t)，t 是目标的一部分，延长 t 后概率自然可以变化；不要把不同时域的概率相等作为收敛门。比较时必须使用共同物理时间区间，寿命统计则检查估计区间、删失和随新增数据的稳定性。

### 7.2 初态重复与无偏存储

每个条件采用多个独立平衡初态，每个初态多个独立热噪声重复。规划约 32 个初态×4 个噪声重复作为 128 路径 pilot 起点；最终按方差分解/精度扩充初态与重复数，不把这一数目视为生产充分性证书。

组内正式路径使用同一个固定时间网格和观察时长，无论成功、失败、返回，都积分到终点。跨尺寸同条件比较尽量使用共同物理窗口；更长窗口可单独保留，不在比较时隐去差异。不同条件允许有预先冻结的不同 T_obs，但模型必须输入真实时间与 mask，不得按各自结束时间归一化后冒充相同动力学。

每条路径 sample_weight=1；所有构型、噪声种子和结果保留。重要性采样/稀有事件加速不属于本轮无偏主集，未经独立加权方法设计不得混入。

### 7.3 事件定义：无事件不等于未决

用独立平衡数据标定正/负有序盆，不统一硬编码 |n_z|=0.8。判据同时检查 |n|、空间结构和驻留，区分临界失序导致的变号与两个有序盆间转换。

终态与事件至少保存：

```text
first_crossing_time, first_committed_switch_time
event_observed, censor_time, terminal_basin, ordered_state_flag
outcome: no_crossing / crossed_returned / committed_switch /
         critical_disordering / unresolved_transition
```

- 稳定留在原盆而未翻转：是有效 no_crossing 路径；首达时间右删失，不是质量失败。
- 驻留判据是预注册操作定义，不能保证热噪声下永不再翻转；保存全部后续重返与重复事件。
- unresolved_transition 指观察末端无法归入稳定盆的过渡，不是“所有没翻转的路径”。超过预注册比例时分析其来源，延长独立 pilot 或限制任务范围，不删除这些路径。
- 接近临界区 |n| 消失后的正负抖动不得计成低能垒稳定翻转。
- 不能要求有限温零场的所有路径最终永久停在一个盆；不能以“直到成功”为单条停止规则。

### 7.4 无事件和资源不可达时的合法结论

允许低温大尺寸路径只有盆内涨落，这是有效研究结果。对于固定初态下 n 个真正独立且零事件的重复，报告二项零事件概率上界；若存在初态层级相关，使用匹配的分层方法，不能直接将所有帧或相关重复当独立样本。

若预算内无法估计某个稀有翻转率，输出 `inconclusive_for_switching_rate`、已模拟总暴露时间、删失统计、可检出概率范围和预计追加成本。继续其他可行条件；不得加场、改材料参数、删掉零事件组或升温进入失序区来冒充完成。

### 7.5 数值、机制与统计门

注册 `acceptance.yaml` 后使用独立确认批次执行：

- dt/dt2/dt4：相同物理时间，比较均值/方差、CDF、能量/结构相关和事件概率；随机路径不要求逐点相同。耦合用于降低比较方差，不能取代弱收敛。
- 保存间隔：同一细采样数据按 1/2/4 下采样，比较事件检测与空间机制；首次到达误差及漏检率需落入注册容差。
- 空间：48/64/96 起步，必要时 128。尺寸泛化研究允许真实有限尺寸效应，不能强制所有尺寸事件率相等。检查的是机制可容纳、边界影响和数值解释；若宣称热力学极限才要求相应尺寸收敛。
- 机制标签需同时用结构因子、局域 Néel 场、畴壁/团簇演化核验；阈值敏感性不改变主结果结论。非均匀程度超过阈值不自动等于成核。
- 默认主验证精度设计：固定时域常见事件概率的 95% CI 半宽<=0.05；若声称相对精度，稀有类别相对半宽<=20%；关键平均/空间观测量数值误差预算<=5%。必须在新确认数据前按具体量定义分母、近零绝对容差、多重比较策略与数据量。
- dt 差异的 CI 应整体落在注册等价带内，不以 p>0.05 或 CI 相互重叠证明等价。达不到精度就增加独立数据或限制结论，不改验收阈值。

## 8. P5/P6：冻结正式数据协议与格式

只有文献矩阵及无场目标条件的证书全部满足，独立认证程序才允许新版本 `production_enabled=true`。各证书必须带 scope、code/config/reference 哈希、实际量值和判定；代码/参数变动要做影响分析并使相关证书失效。

建议使用新名称 `data/datasets/gomonay_zero_field_v1/`，避免与历史含 SOT 的 standard_v2/旧 V3 混淆。具体 schema 版本在盘点后注册，不虚称当前 loader 已支持。

目录约定：

```text
conf/zero_field_gomonay/                  # 候选和验收配置
conf/frozen/zero_field_gomonay/<campaign>/
data/research/zero_field_gomonay/<run_id>/ # pilot / 平衡校准
data/datasets/gomonay_zero_field_v1/      # 正式分片、初态池、split 清单
output/zero_field_program/<program_id>/  # 总进度、认证矩阵、资源和交接
assets/research/zero_field_gomonay/<run_id>/
logs/zero_field_gomonay/<run_id>/
```

每条训练样本必须保存：完整 spins、真实时间、初态、mask、晶格/基矢/边界、子晶格映射、Hamiltonian/约化温度/alpha、零场声明、初态组、准备链、噪声 seed、权重、split、事件与删失元数据。100/110 的 2/4 位点晶胞需要真实映射，不可截断成固定两个通道。

raw 以审计所需双精度保存；如生产转 float32，先量化对能量/事件/空间观测的影响，记录数据派生关系，不用 float32 文件套双精度 1e-10 模长门。

实现 HDF5 分块、流式输出、原子完成标记、完整性/哈希和独立 certifier。分片完成不等于物理认证。大文件按现有 LFS/分片政策管理，不把全部 raw 直接提交普通 Git。

## 9. P7：训练用途、划分与创新点验证

### 9.1 三类数据不能混用

- 文献验证集：频谱、静态/自由运动壁、其他材料基准，证明数据源正确。
- 无场主训练集：多个尺寸和温度下的完整随机轨迹，学习 p[S(0:T)|S0,theta,alpha,H,geometry]。
- 冻结最终测试集：独立初态组、种子、未见温度和尺寸；不参与阈值、归一化、checkpoint 或模型选择。

本阶段无驱动幅度/脉冲泛化主张。可以保留零值输入接口，但不能因为模型接受这些参数就声称已经学会其变化。

### 9.2 推荐划分

- 开发训练：L16/32 与能够承载目标机制的 L48/64；不能只用小盒涨落宣称学会未出现的成核机制。
- 按 parent_chain/initial_state 组整体划分 train/validation/test，继承整个组的噪声重复；建议 80/10/10 作为起点，但最终测试样本数以精度门为准。
- 温度留出：在生成前整组冻结未见温度；明确区间内插值和区间外外推，不能训练后挑最好看的温度。
- 大尺寸测试：全新 L96/128 动态批次；做相同绝对温度/时间/边界下与独立 LLG 的对照。历史反复查看过的 L96 仅作开发。
- 固定初态的新噪声测试与完全未见初态测试分别报告。最终测试只在预注册模型选择结束后评估；若根据结果调参，该测试退为开发并建立新最终批次。
- 归一化参数仅从训练集拟合；物理盆地校准是独立、事先冻结的数据，不使用最终动态测试轨迹。

### 9.3 晶向与 AFM 对照的边界

J_tilde=0 是匹配消融，不是另一篇独立材料复现。若把 J_tilde 变化作为条件泛化，训练/测试需显式输入其物理参数并整组划分。

无外场、均匀初态、对称周期盒中的全局翻转率不自动具有可比较的“驱动晶向”。研究方向差异应使用方向分辨的相关函数/结构因子，或明确规定的定向纹理任务。联合 C4 操作的等价情况应恢复对称关系，不能将坐标旋转产生的变化当新物理。

定向预制壁任务与均匀初态自发成核任务分别训练/评估或显式提供任务条件，不能混合解释机制权重。

### 9.4 训练与验收顺序

1. 先实现新格式 loader 并用真实小分片验证初态、时间、几何、mask、split；新增有意义的回归测试。
2. 少量轨迹过拟合 -> 单条件路径分布 -> 多温度联合 -> L48/64 -> 冻结大尺寸/温度测试。
3. 比较确定性基线、合适的非等变随机生成基线、球面/等变/条件注入消融；采用相同数据和明确记录的模型容量与训练预算。
4. 至少三个独立训练种子，使用配对评估初态；统计不确定度区分真实 LLG 样本、生成样本及训练种子。
5. 主指标：终态与全路径分布、事件/返回/删失、首次到达与驻留、能量、时间相关、空间结构因子、机制概率。MSE 和平均曲线仅为辅助。
6. 若声称加速，在相同硬件及目标统计误差下比较吞吐/延迟/显存，并报告训练与数据生成成本、摊销场景。不得只比单次前向和完整 LLG 的不等价工作量。

同体系的新噪声、初态、温度和尺寸泛化可以构成方法价值；每个材料分别训练仅说明方法可复用，不等于单 checkpoint 跨材料零样本泛化。

## 10. 服务器实际执行、计时与长任务恢复

### 10.1 首次入口

以下命令在服务器项目根目录执行，先核验路径和现有包装器；不在本地 Windows 假装运行 Slurm：

```bash
git status --short
git rev-parse HEAD
bash ../run_zrs_mag.sh scripts/config/validate_literature_configs.py
bash ../run_zrs_mag.sh -m pytest scripts/tests -q
```

根据 P0 做受影响测试与完整必需门。先检查现有 `submit_remaining_validation.py`、约化 campaign 工具、按文献的 run/analyze/plot、温度扫描和初态池入口，复用可用实现；旧接口未连接新约化模型时先适配，不能只编写一个新的 sbatch 包装旧物理。

无场程序需要的尚缺功能必须实际实现并验证：状态盘点/证书依赖、无场生成、平衡池、事件检测、长时恢复、split/metadata 审计和报告。可增加最少的新脚本，不进行无关重构。当前不存在的命令不得在交接中冒称可执行。

### 10.2 有限资源下持续推进

- 沿用 zrs-mag 环境；不要安装到 base。GPU 仅在有效 Slurm 分配中使用；CPU 生产提交 fat 或服务器批准的队列，禁止长期占用登录节点。
- 先做代表性至少 10000 积分步计时，包含保存与压缩开销；BVP/分析采用相应实际工作单元计时。测量峰值内存、每帧字节、磁盘总量、队列 walltime，按至少 1.5 裕量申请。
- 单节点多进程控制 BLAS/PyTorch 线程，防止 CPU 超订阅；GPU/CPU 的 dtype 与随机数差异记录并对关键观测做一致性检查。
- 批量任务冻结代码和 YAML、哈希、依赖图及有限计算上限；在预算文件中写明本 campaign 的最大作业数、GPU/CPU 小时、存储量和重试次数。不得以无限自动重提交代替计划。
- 队列超时可续算，但必须保存步号、spins、每条 RNG 状态、物理/保存时间、事件历史和写入游标；“仅设置原 seed 重新开始”不是续算。
- 续算实现先与不中断运行在同设备同版本上比较。断点不可恢复时保留失败文件，新 run 重做并记录关系，不拼接不连续路径或删除失败种子。
- 数值失败停止该模型依赖任务，基础热浴失败停止共享有限温生产。IO/调度失败与物理失败分开；分析恢复不修改原 Slurm 退出码。

### 10.3 自动推进的边界

执行器完成当前可行阶段后，应推进下一已满足证书依赖的阶段，不等待用户逐项催促。资源上限达到、文献无法核验、无事件导致目标不可估计时停止相应分支并给出具体证据和最小后续需求。禁止把“已提交”“有图片”“程序返回0”写成目标已完成。

每个 paper_id 保持独立 report.md/report.json、manifest、reference、raw、derived、figures 与 animations。新增总索引必须链接真实存在文件。
